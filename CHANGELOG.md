# Changelog

## 1.0.0 - Initial source release
- Added client-only Forge 1.8.9 mod entry point.
- Added configurable particle reduction, entity-shadow disable, render distance, and FPS cap.
- Added restoration of vanilla settings on world exit/unload.
- Excluded all Discord, webhook, chat-monitoring, telemetry, and data-sharing functionality.
- No texture or resource-pack modifications.
- Binary compilation and runtime tests remain pending; see README.md.
